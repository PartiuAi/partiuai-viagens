# PartiuAí

Repositório do projeto **PartiuAí** — aplicação web para planejar viagens por carro, ônibus,
táxi e moto.

```
PartiuAí/
├── referencias/     # logo, paleta de cores e wireframes (mobile e desktop) fornecidos
└── frontend/        # aplicação front end (React + TypeScript + Vite)  ← etapa atual
```

## Etapa atual: front end

O front end está completo e pronto para aprovação visual. Ele foi construído a partir das
referências da pasta `referencias/`, usando a paleta oficial da marca
(#0E0064, #5472FF, #8C52FF, #FFFFFF) e o logo original.

**Nenhum back end foi desenvolvido.** Todos os dados exibidos são simulados no front end e
serão plugged nas APIs quando a etapa de back end começar.

Para rodar:

```bash
cd frontend
npm install
npm run dev
```

Detalhes de estrutura, tokens e próximos passos: [`frontend/README.md`](frontend/README.md).
